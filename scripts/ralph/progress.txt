## Codebase Patterns
- Code lives in `src/config-gen/` (NOT `packages/generator/` as PRD says — adapt paths accordingly)
- Tests use Vitest with `import { describe, it, expect } from 'vitest'`
- Test files are in `__tests__/` directories adjacent to source
- Integration test fixtures in `src/config-gen/__tests__/integration/fixtures/`
- Integration test expected outputs in `src/config-gen/__tests__/integration/expected/`
- Root exports from `src/index.ts` re-export from `src/config-gen/index.ts`
- Typecheck: `npx tsc --noEmit --target es2022 --module nodenext --moduleResolution nodenext --strict --skipLibCheck --esModuleInterop <files>`
- Run tests: `npx vitest run`
- The tsconfig extends `@docs/configs/tsconfig/base.json` which doesn't exist in this repo — use explicit tsc flags instead
- CLI is at `src/config-gen/cli.ts`
- `@types/node` needed for Node.js type definitions (was added as devDep)
